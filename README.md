# Enterprise Cloud Identity & ITSM Support Lab

## Overview

This project simulates the day-to-day responsibilities of an IT Service Desk Engineer in an enterprise environment. It demonstrates hands-on administration of Microsoft Entra ID alongside IT Service Management (ITSM) processes in ServiceNow.

The lab is built around a fictional organization, **Apex Financial Solutions**, where common Service Desk tasks such as user administration, access management, incident handling, and service request fulfillment are performed using realistic business scenarios.

---

## Objectives

- Manage user identities in Microsoft Entra ID.
- Configure and manage security groups and role assignments.
- Perform common identity administration tasks.
- Handle incidents and service requests using ServiceNow.
- Follow structured ITSM workflows for investigation, documentation, and resolution.
- Simulate real-world Service Desk scenarios commonly encountered in enterprise environments.
